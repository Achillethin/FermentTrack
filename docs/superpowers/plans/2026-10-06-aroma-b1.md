# Aroma B1 — Infrastructure, Full Compound Catalogue, Kombucha and Kefir Aroma, Aroma UI

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Odorant tracers on every forecast ensemble member: all 85 curated compounds catalogued, the infrastructure and six mechanism templates that cover kombucha and kefir, the aroma API, and the aroma strip + drill-down in the Taste & aroma lens.

**Architecture:** The kinetic solve stays as is. A diagnostics hook makes the engine report per-organism growth μⱼXⱼ, substrate flux vⱼ and CO₂ flux at the output times (raw states kept by inference). A new pure module `prediction/aroma.py` integrates linear tracers `dC/dt = S(t) − K(t)·C` exactly per interval, template by template in dependency order, then turns concentrations into odour activity (threshold prior × shared matrix factor × pH neutral fraction) and series sums. `derived.evaluate` calls it; the sensory block and series carry the result; the frontend draws it.

**Tech Stack:** Python 3.11, numpy/scipy, Pydantic, pytest, mypy (`--python-version 3.12`, see note), ruff; React 18 + Vite + Tailwind; node self-check scripts.

**Spec:** `docs/superpowers/specs/2026-10-05-aroma-curation.md` (the data and the § 7 tests) and `docs/superpowers/specs/2026-10-02-flavour-nutrition-design.md` § 4, 6, 8 (architecture, UI, API). This plan is **B1** of the curation spec's § 11.2 order: steps 1 (infrastructure), 2 (T1, T2, T3, T5, T9 → kombucha and kefir) and the UI of step 10 for what exists. T8 is included only for initial pools (tea, milk) and their microbial reduction/release, which kefir and kombucha need.

**Later plans (each its own plan, written when the previous one is merged):**
- **B2:** T4 citrate → α-acetolactate → diacetyl/acetoin chain (cheese, kefir C4 cells) and T11 miso (HEMF, furanones, maltol, Ehrlich in miso).
- **B3:** T6 glucosinolates, T7 sulfur and T8 vegetable LOX (lacto-ferment), plus T8 flour aldehydes and T10 (sourdough, including the bake path).
- **B4:** the acetic-acid-bacteria sink and wine-base pools (vinegar), mould C8 compounds (koji), and garum.
- **P0 curation pass:** estimated, wide initial amounts for the ingredient-only precursors still at zero (spices, flour sotolon, rice 2-acetyl-1-pyrroline, tea and soy phenolic acids). This fills the 30 zero cells, per the owner's goal of a complete palette.

```python
"""Freeze the curation spec's § 3 compound table into src/.../aroma_compounds_v1.csv.

Run: python scripts/build_aroma_compounds.py   (tests/test_aroma_catalogue.py guards drift)
"""

from __future__ import annotations

import csv
import re
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
SPEC = ROOT / "docs/superpowers/specs/2026-10-05-aroma-curation.md"
OUT = ROOT / "src/fermenttrack/prediction/aroma_compounds_v1.csv"
FIELDS = (
    "key", "name", "pubchem", "chebi", "kegg", "descriptor", "series", "thr_median", "thr_lo",
    "thr_hi", "basis", "ph_kind", "pka", "templates", "status", "conc_only", "drilldown_only",
    "p0_pending",
)  # fmt: skip
_SECTION = re.compile(r"^## 3\. Compound table$(.*?)^## 4\.", re.M | re.S)


def _id(part: str) -> str:
    tok = part.strip().split("/")[0].split()[0] if part.strip() else ""
    return "" if tok in ("—", "-") else tok


def parse_compound_table(spec_text: str) -> list[dict[str, str]]:
    m = _SECTION.search(spec_text)
    if not m:
        raise ValueError("§ 3 not found")
    out = []
    for line in m.group(1).splitlines():
        if not line.startswith("| ") or line.startswith("| key") or line.startswith("|---"):
            continue
        cells = [c.strip() for c in line.strip().strip("|").split("|")]
        if len(cells) != 9:
            raise ValueError(f"expected 9 cells: {line}")
        key, name, ids, desc, thr, basis, ph, template, status = cells
        idp = (ids.split("·") + ["", "", ""])[:3]
        dm = re.match(r"(.*)\(([^()]*)\)\s*$", desc)
        descriptor, series = (dm.group(1).strip(), dm.group(2)) if dm else (desc, "")
        nums = [] if thr.startswith("none") else re.findall(r"\d+(?:\.\d+)?", thr.split("(")[0])
        b = re.sub(r"\*", "", basis).split("·")[0].strip().split()[0].rstrip(".")
        ph_kind, pka = "", ""
        if ph.startswith(("acid", "base")):
            ph_kind, pka = ph.split()[0], re.findall(r"\d+(?:\.\d+)?", ph)[0]
        s = re.sub(r"\*", "", status)
        kind = "drop" if s.startswith("drop") else "inactive" if s.startswith("inactive") else "active"
        out.append({
            "key": key, "name": name, "pubchem": _id(idp[0]), "chebi": _id(idp[1]),
            "kegg": _id(idp[2]), "descriptor": descriptor,
            "series": ";".join(x.strip() for x in series.split(",") if x.strip()),
            "thr_median": nums[0] if nums else "", "thr_lo": nums[1] if nums else "",
            "thr_hi": nums[2] if nums else "", "basis": b, "ph_kind": ph_kind, "pka": pka,
            "templates": ";".join(re.findall(r"T\d+", template)) or ("engine" if "engine" in template else ""),
            "status": kind, "conc_only": "1" if "conc-only" in s else "0",
            "drilldown_only": "1" if "drill-down only" in s else "0",
            "p0_pending": "1" if "P0 pending" in s else "0",
        })  # fmt: skip
    return out


if __name__ == "__main__":
    rows = parse_compound_table(SPEC.read_text(encoding="utf-8"))
    with OUT.open("w", encoding="utf-8", newline="") as f:
        w = csv.DictWriter(f, fieldnames=FIELDS, lineterminator="\n")
        w.writeheader()
        w.writerows(rows)
    print(f"{len(rows)} compounds -> {OUT}", file=sys.stderr)
```

```python
def diagnose(p: EnsembleParams, t: FloatArray, y: FloatArray) -> dict[str, FloatArray]:
    """Per-organism growth (g/kg/h), hexose-equivalent substrate flux (g/kg/h) and the CO2
    flux (g/kg/h) at each time of a solved trajectory, from its raw states y (N, T, S).
    One RHS evaluation per time; the solve itself is not touched."""
    n, m, nt = p.n, len(p.organisms), len(t)
    out = {f"{k}:{j}": np.zeros((n, nt)) for j in range(m) for k in ("growth", "flux")}
    out["co2"] = np.zeros((n, nt))
    diag: dict[str, FloatArray] = {}
    rhs = make_rhs(p, None, diag)
    for i, ti in enumerate(t):
        rhs(float(ti), np.ascontiguousarray(y[:, i, :]).reshape(-1))
        for key, v in diag.items():
            out[key][:, i] = v
    return out
```

```python
"""Aroma tracers on a forecast ensemble (increment B).

Each odorant obeys dC/dt = S(t) - K(t)·C on every member, with S and K built from the
engine's per-organism growth and flux, its pools, pH and temperature. Templates run in
dependency order (precursor -> product), so each tracer is linear with known coefficients
and is integrated exactly per interval. Data: aroma_data.py; design:
docs/superpowers/specs/2026-10-05-aroma-curation.md.
"""

from __future__ import annotations

import numpy as np

from fermenttrack.prediction import aroma_data as A
from fermenttrack.prediction.priors import FloatArray

Draws = dict[str, FloatArray]


def _phi(x: FloatArray) -> tuple[FloatArray, FloatArray]:
    """phi1 = (1 - e^-x)/x and phi2 = (x - 1 + e^-x)/x^2, stable near 0."""
    small = x < 1e-4
    xs = np.where(small, 1.0, x)
    em = -np.expm1(-xs)
    p1 = np.where(small, 1.0 - x / 2.0 + x * x / 6.0, em / xs)
    p2 = np.where(small, 0.5 - x / 6.0 + x * x / 24.0, (xs - em) / (xs * xs))
    return p1, p2


def integrate(t: FloatArray, source: FloatArray, k: FloatArray, c0: FloatArray) -> FloatArray:
    """C' = S - K·C with S linear and K at its interval mean: exact per interval."""
    n, nt = source.shape
    c = np.empty((n, nt))
    c[:, 0] = c0
    for i in range(nt - 1):
        h = float(t[i + 1] - t[i])
        if h <= 0.0:
            c[:, i + 1] = c[:, i]
            continue
        x = 0.5 * (k[:, i] + k[:, i + 1]) * h
        p1, p2 = _phi(x)
        s0 = source[:, i]
        s1 = (source[:, i + 1] - s0) / h
        c[:, i + 1] = np.maximum(c[:, i] * np.exp(-x) + s0 * h * p1 + s1 * h * h * p2, 0.0)
    return c


def neutral_fraction(ph: FloatArray, kind: str, pka: float | None) -> FloatArray:
    """Share of an acid or amine in its volatile, uncharged form (curation spec D5)."""
    if kind == "acid" and pka is not None:
        return np.asarray(1.0 / (1.0 + 10.0 ** (ph - pka)))
    if kind == "base" and pka is not None:
        return np.asarray(1.0 / (1.0 + 10.0 ** (pka - ph)))
    return np.ones_like(np.asarray(ph, dtype=float))


def draws(n: int, seed: int) -> Draws:
    """Template parameters, thresholds and the shared matrix factor per member: nothing
    observes them yet, so prior draws are their posterior (spec 2026-10-02 § 1)."""
    priors = dict(A.PARAMS)
    priors.update({f"thr:{k}": c.threshold for k, c in A.COMPOUNDS.items() if c.threshold})
    z = np.random.default_rng(seed).standard_normal((n, len(priors)))
    out = {}
    for j, (k, p) in enumerate(priors.items()):
        v = np.asarray(p.value(z[:, j]))
        if p.scale == "lin":  # split normal tails can cross 0 (rates) or 1 (shares)
            v = np.clip(v, 0.0, 1.0 if k.startswith(("share_", "split_", "excr_")) else np.inf)
        out[k] = v[:, None]
    return out


def kaw25(key: str, d: Draws) -> FloatArray | float:
    """K_aw at 25 °C: measured (§ 5.12), else the class stand-in × the member's stand-in factor."""
    if key in A.KAW:
        return A.KAW[key]
    return A.KAW[A.KAW_CLASS[key]] * d["kaw_standin"]


def volatility(
    key: str, temp: FloatArray, f_neutral: FloatArray, co2_rate: FloatArray, d: Draws,
    co2_escapes: bool, k_surf_d: FloatArray | float,
) -> FloatArray:  # fmt: skip
    """Loss rate (1/h): CO2 stripping of the neutral form plus open-surface loss (§ 5.12)."""
    kaw = kaw25(key, d) * d["kaw_tfactor"] ** ((temp - 25.0) / 10.0) * f_neutral
    strip = (np.maximum(co2_rate, 0.0) / 44.01 * 24.5) * kaw * d["kaw_eta"] if co2_escapes else 0.0
    return np.asarray(strip + k_surf_d * kaw / 24.0)


def odour_activity(conc: FloatArray, key: str, f_neutral: FloatArray, d: Draws) -> FloatArray:
    """Concentration of the volatile form over the member's threshold (× shared matrix factor)."""
    return np.asarray(conc * f_neutral / (d[f"thr:{key}"] * d["matrix"]))
```
