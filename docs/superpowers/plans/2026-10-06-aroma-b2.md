# Aroma B2 — Sourdough: Flour Pools, Ferulic Acid, the α-Acetolactate Sugar Route, Chained Phases

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sourdough gets aroma, both on a plain sourdough batch (one solve) and on a bake plan (levain → dough → proof, chained solves), driven by the flours and the organisms; curation tests 14–15 pinned.

**Architecture:**
- **Segments.** The aroma layer integrates over a list of `Segment`s: one per solve (one for an ordinary batch, one per phase of a bake plan). Each carries its own engine parameters, raw states and phase clock (temperature and `engine.diagnose` run on that clock), the fresh ingredients of its mix, and the mass share carried in from the previous segment. At a mix, every tracer and internal state starts at `carry × (previous end) + fresh ingredient pools`, the same rule the engine applies to its pools (`SourdoughModel._mix`).
- **New templates:** flour pools (§ 6.2, re-derived with the new threshold medians), T8 reduction (exists since B1), T10 ferulic acid → 4-vinylguaiacol (§ 5.10), and the T4 sugar route through α-acetolactate (D3), which gives sourdough its diacetyl and 2,3-pentanedione.
- **Draw streams.** Each aroma parameter draws from its own seeded stream, so a parameter added by a later plan never moves the draws (and the calibration) of the earlier ones.

**Tech Stack:** Python 3.11, numpy/scipy, pytest, mypy (`--python-version 3.12`), ruff. No frontend change (the palette and strip are type-agnostic).

**Spec:** `docs/superpowers/specs/2026-10-05-aroma-curation.md` (§ 4.3 sourdough evidence, § 5.4, § 5.8, § 5.10, § 6.1–6.2, § 7 tests 14–15, § 10.3 B1 notes, § 11.2 order) and `docs/superpowers/specs/2026-10-02-flavour-nutrition-design.md` § 1 (bake-phase carry-over of tracers).     # diacetyl (oxidative share) or acetoin; diacetyl and 2,3-pentanedione are reduced by
    # yeast and LAB (Lactococcus slowly); acetoin is reduced to 2,3-butanediol
    al_made = 1000.0 * d["b_acetoin_lab"] * f_lab / mw["acetoin"]  # µmol/kg/h
    al0 = tr.start("_acetolactate")
    if np.any(al_made > 0.0) or np.any(al0 > 0.0):
        k_al = d["al_decay"] * q("al_q10", 30.0)
        al = integrate(ctx.t, al_made, k_al, al0)
        tr.conc["_acetolactate"] = al
        decayed = k_al * al  # µmol/kg/h
        ox = d["share_al_ox"]
        for key, rate, via in (
            ("diacetyl", ox, "sugar → α-acetolactate"),
            ("pentanedione_23", ox * d["pd_per_diacetyl"], "sugar → α-acetolactate"),
            ("acetoin", 1.0 - ox, "sugar → acetoin"),
        ):
            if tr.add(key, rate * decayed * mw[key]):
                tr.organisms(key, LAB, via)
    k_dr = (d["kmax_diacetyl_red"] / 24.0 * _gate(ctx, YEAST | {"lab", "lab_hetero"})
            + d["kmax_diacetyl_red_lc"] / 24.0 * _gate(ctx, {"lactococcus"}))  # fmt: skip
    for key in ("diacetyl", "pentanedione_23"):

    if "diacetyl" in tr.src or "diacetyl" in tr.c0:
        dia = tr.solve("diacetyl")
        if tr.add("acetoin", k_dr * dia * mw["acetoin"] / mw["diacetyl"]):

_STATES = ("_acetolactate", "_ferulic_bound", "_ferulic_free")  # carried across a mix


def chain(
    segments: list[Segment], profile: FermentProfile, d: Draws, co2_escapes: bool
) -> tuple[dict[str, FloatArray], dict[str, list[Route]], FloatArray, Context]:
    """Concentrations over consecutive solves: each starts from carry x the previous end
    plus its fresh ingredients (the engine's own mixing rule, SourdoughModel._mix)."""
    parts: list[dict[str, FloatArray]] = []
    routes: dict[str, list[Route]] = {}
    phs: list[FloatArray] = []
    inherit: dict[str, FloatArray] = {}
    ctx: Context | None = None
    for seg in segments:
        ctx = build_context(seg, profile, co2_escapes)
        conc, r = concentrations(ctx, d, {k: seg.carry * v for k, v in inherit.items()})
        for k, rs in r.items():
            for x in rs:
                if x not in routes.setdefault(k, []):
                    routes[k].append(x)
        parts.append(conc)
        phs.append(ctx.ph)
        inherit = {k: v[:, -1] for k, v in conc.items() if k in A.COMPOUNDS or k in _STATES}
    assert ctx is not None
    keys = list(dict.fromkeys(k for p in parts for k in p))
    out = {
        k: np.concatenate(
            [p.get(k, np.zeros_like(ph)) for p, ph in zip(parts, phs, strict=True)], axis=1
        )
        for k in keys
    }
    return out, routes, np.concatenate(phs, axis=1), ctx
